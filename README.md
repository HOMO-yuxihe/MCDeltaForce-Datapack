## 部署
### 据点
要创建据点，需要创建一个标记实体，位于据点矩形中三轴坐标均最小的顶点，其NBT依据以下格式：
```
{
    display: {
        gti: {
            status: [
                '{"text":"  <据点名>","color":"red"}',
                '{"text":"\\u0108\\u0102\\u0201  ","color":"red","font":"df:space"}'
            ]
        },
        haavk: {
            status: [
                '{"text":"  <据点名>","color":"green"}',
                '{"text":"\\u0108\\u0102\\u0201  ","color":"green","font":"df:space"}'
            ]
        }
    },
    display_name: "<据点名>",
    name: "<据点名(大写变成小写)>"
}
```
注意：字符串内空格不要改，除非显示错位。
